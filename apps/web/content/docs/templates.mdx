Prebuilt editor configurations that come with custom controls already integrated. Each template is a complete `@editorcn/editor` setup with specific controls tailored to a use case — just install and go.

Install the base editor and the controls you need, or install everything at once.

<div className="rounded-lg border border-border p-6 mb-8">

### Document Editor

<div className="text-sm text-muted-foreground mb-4">
  Font Family Select · Font Size · Highlight Color Popover
</div>

A rich text editor focused on document styling — choose fonts, set text size, and highlight important content.

**Install the editor:**

<CodeBlockCommand
  __npm__={"npx shadcn@latest add @editorcn/editor"}
  __yarn__={"yarn dlx shadcn@latest add @editorcn/editor"}
  __pnpm__={"pnpm dlx shadcn@latest add @editorcn/editor"}
  __bun__={"bunx shadcn@latest add @editorcn/editor"}
/>

**Then install the controls:**

<CodeBlockCommand
  __npm__={
    'npx shadcn@latest add "https://editorcn.vercel.app/r/custom-controls/font-family-select" "https://editorcn.vercel.app/r/custom-controls/font-size" "https://editorcn.vercel.app/r/custom-controls/highlight-color-popover"'
  }
  __yarn__={
    'yarn dlx shadcn@latest add "https://editorcn.vercel.app/r/custom-controls/font-family-select" "https://editorcn.vercel.app/r/custom-controls/font-size" "https://editorcn.vercel.app/r/custom-controls/highlight-color-popover"'
  }
  __pnpm__={
    'pnpm dlx shadcn@latest add "https://editorcn.vercel.app/r/custom-controls/font-family-select" "https://editorcn.vercel.app/r/custom-controls/font-size" "https://editorcn.vercel.app/r/custom-controls/highlight-color-popover"'
  }
  __bun__={
    'bunx shadcn@latest add "https://editorcn.vercel.app/r/custom-controls/font-family-select" "https://editorcn.vercel.app/r/custom-controls/font-size" "https://editorcn.vercel.app/r/custom-controls/highlight-color-popover"'
  }
