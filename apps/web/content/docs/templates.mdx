# Templates

Prebuilt editor configurations that come with custom controls already integrated. Each template is a complete `@rtecn/editor` setup with specific controls tailored to a use case — just install and go.

Install the base editor and the controls you need, or install everything at once.

<div className="rounded-lg border border-border p-6 mb-8">

### Document Editor

<div className="text-sm text-muted-foreground mb-4">
  Font Family Select · Font Size · Highlight Color Popover
</div>

A rich text editor focused on document styling — choose fonts, set text size, and highlight important content.

**Install the editor:**

<Tabs defaultValue="npm" groupId="pm">
  <TabsList>
    <TabsTrigger value="npm"><NpmIcon className="h-4 w-4" /> npm</TabsTrigger>
    <TabsTrigger value="yarn"><YarnIcon className="h-4 w-4" /> yarn</TabsTrigger>
    <TabsTrigger value="pnpm"><PnpmIcon className="h-4 w-4" /> pnpm</TabsTrigger>
    <TabsTrigger value="bun"><BunIcon className="h-4 w-4" /> bun</TabsTrigger>
  </TabsList>
  <TabsContent value="npm">

```shell frame="none"
npx shadcn@latest add @rtecn/editor
```

  </TabsContent>
  <TabsContent value="yarn">

```shell frame="none"
yarn dlx shadcn@latest add @rtecn/editor
```

  </TabsContent>
  <TabsContent value="pnpm">


  </TabsContent>


  </TabsContent>
</Tabs>
