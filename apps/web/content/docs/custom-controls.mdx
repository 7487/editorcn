# Custom Controls

Pre-built custom toolbar controls — each template has a live **Preview** tab and a **Code** tab with the full source you can copy.

All controls use `useRichTextEditorContext` from `@rtecn/editor` to access the editor instance. Add them as children inside `<RichTextEditor.Toolbar>`.

Install all controls at once:

<Tabs defaultValue="npm" groupId="pm">
  <TabsList>
    <TabsTrigger value="npm"><NpmIcon className="h-4 w-4" /> npm</TabsTrigger>
    <TabsTrigger value="yarn"><YarnIcon className="h-4 w-4" /> yarn</TabsTrigger>
    <TabsTrigger value="pnpm"><PnpmIcon className="h-4 w-4" /> pnpm</TabsTrigger>
    <TabsTrigger value="bun"><BunIcon className="h-4 w-4" /> bun</TabsTrigger>
  </TabsList>
  <TabsContent value="npm">

```shell frame="none"
npx shadcn@latest add "https://rtecn.space/r/custom-controls"
```

  </TabsContent>
  <TabsContent value="yarn">

```shell frame="none"
yarn dlx shadcn@latest add "https://rtecn.space/r/custom-controls"
```

  </TabsContent>
  <TabsContent value="pnpm">

```shell frame="none"

```

  </TabsContent>
  <TabsContent value="bun">


  </TabsContent>
</Tabs>
