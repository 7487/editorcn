---
title: Custom Controls
description: Ready-to-use custom toolbar controls with live preview and source code.
---

Pre-built custom toolbar controls — each template has a live **Preview** tab and a **Code** tab with the full source you can copy.

All controls use `useRichTextEditorContext` from `@rtecn/editor` to access the editor instance. Add them as children inside `<RichTextEditor.Toolbar>`.

Install all controls at once:

<CodeBlockCommand
  __npm__={"npx shadcn@latest add \"https://rtecn.space/r/custom-controls\""}
  __yarn__={"yarn dlx shadcn@latest add \"https://rtecn.space/r/custom-controls\""}
  __pnpm__={"pnpm dlx shadcn@latest add \"https://rtecn.space/r/custom-controls\""}
  __bun__={"bunx shadcn@latest add \"https://rtecn.space/r/custom-controls\""}
/>

You can also copy the source directly from the **Code** tab in each control below.
